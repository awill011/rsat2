What this does
The Reading Strategies Assessment Tool (RSAT) measures how well participants comprehend a text by analyzing their think-aloud verbal protocols. This pipeline automates that scoring process — taking raw text responses and computing three key metrics:
SW/PW (paraphrasing) — how much content vocabulary from the source text appears in the participant's response
Total word count (effort) — overall verbosity as a proxy for engagement
SNO/PW (elaboration) — degree to which the participant extends beyond the source text
Why it matters
Manual RSAT scoring is time-intensive and subject to human error. This tool replaces a largely manual process with a reproducible Python pipeline, enabling the LLT Lab to process larger participant datasets faster and more consistently.
